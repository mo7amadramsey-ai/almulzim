# المُلزم (Almulzim)

نظام انضباط دراسي لأندرويد: دمج «المرشد الدراسي» + «Focus Lock» بهوية Midnight Intelligence (خط Tajawal، RTL).

**من المرشد:** استيراد مودل بالزاحف المتوازي، خطة ذكية، تصنيف الفصول، التقويم، المتابعة، التنبيهات، المرشد الذكي (Gemini)، القفل الدراسي بالمؤقت.
**من Focus Lock:** يوتيوب مقيّد، تصفح مودل وتحميل، مكتبة الفيديوهات والمشغّل، المستندات (PDF/Word/Excel/PowerPoint)، قفل صارم (إمكانية الوصول / Device Owner)، قفل البصمة.

الشاشات: اليوم · الخطة · المواد · المتابعة · المزيد.
البناء: كل push يشغّل GitHub Actions ويرفع APK في Releases (عند الفشل: فرع `buildlog`).
انظر `docs/STATUS.md` لما هو منفّذ وما تبقّى من وثيقة المواصفات.
